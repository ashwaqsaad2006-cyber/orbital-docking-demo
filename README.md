# من الإطلاق إلى الالتحام

محاكاة تفاعلية بالعربية توضّح مراحل الالتقاء المداري والالتحام: إطلاق مركبة من الأرض، ثم مرحلة الطور، فالاقتراب البعيد والقريب، وصولًا إلى التلامس وإحكام الأقفال.

من إنتاج منصة **ذرة فهم**.

## الملفات

- `index.html`: بنية الصفحة
- `style.css`: التنسيق (يدعم الوضع الداكن)
- `script.js`: المحاكاة والرسم على `canvas`

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة، ولا يحتاج المشروع إلى أي أدوات بناء أو مكتبات.

## النشر على GitHub Pages

1. ارفع الملفات إلى مستودع جديد.
2. من **Settings → Pages** اختر Branch: `main` والمجلد `/ (root)`.
3. سيصبح الرابط: `https://USERNAME.github.io/REPO/`

## التضمين داخل موقعك

```html
<iframe src="https://USERNAME.github.io/REPO/" width="100%" height="700" style="border:0" loading="lazy" title="من الإطلاق إلى الالتحام"></iframe>
```
